# Carteira-Digital---Java-BDD-JUNIT-e-Github
Projeto para simular as operações básicas de uma cateira digital.

- Java
- Maven
- JUnit
- Cucumber

## Funcionalidades
- Consultar saldo
- Depósitos
- Pagamentos

## Testes
1 - Depositar R$ 100.
2 - Pagar R$ 40
3 - Impedir pagamento de R$ 120 com saldo de R$100

## Como executar
Execute no terminal:
mvn clean test
